# Apps

The Aquarium operator UI moved to its own sibling repository:

`E:\Projects\EpiphanyAquarium`

Epiphany remains the native typed-state, coordination, execution, and backend
organism. Aquarium is the primary graphical client over those surfaces.

Aquarium is the primary client for the next public shape of Epiphany: projects
with Faces. A user should be able to talk to a project, not assemble a perfect
agent prompt. Aquarium should show the repo's Face, heartbeat, memory, pending
turns, current jurisdiction, proposed actions, evidence, conflicts,
uncertainty, and requests for authority so the human can converse, inspect,
approve, refuse, or raise pressure without becoming the agent scheduler.

Routine continuation belongs to Epiphany's physiology. Human attention belongs
on purpose, judgment, exceptions, disagreement, and acceptance. Conversation is
an input and relationship surface, not the hidden operating system.

Discord roles, WebRTC/voice surfaces, stream overlays, native CLIs, and other
CultNet clients are sibling mouths over the same substrate. Aquarium is the
clearest window, not the only door.
